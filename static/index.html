      How the robot learns

      The robot is the agent

      It looks at its situation (where it is, which order, carrying or not), picks one of six actions (up, down, left, right, pick, drop) and sees what happens.

      The warehouse is the environment

      It moves the robot, blocks it at racks, and hands out points. It never tells the robot where to go.

      Points are rewards

      Every move costs a point, bumping or a wrong pick costs more, picking and delivering pay off. Collecting the most points means delivering fast.

      The brain is a Q-table

      One number for every situation and action: the points the robot expects if it does that. After each move it nudges one number:

      new Q = old Q + α × (reward + γ × best next Q − old Q)

      Explore, then exploit

      Early on it mostly tries random moves (ε near 1) to discover the floor. Later it mostly follows its best guesses (ε near 0).

      Things to try

      Set γ to 0.5 and retrain. Make each move cost 0 points. Build a maze. Then use Look inside to see a single update in detail.
